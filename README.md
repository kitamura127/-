# 営業先マップ - モバイル対応版

営業向けの地図アプリケーション。PCとモバイルの両方に対応したレスポンシブUIを実装。

## 機能

### PC版
- 左サイドバー: 営業インテリジェンス（インサイト・新着案件）
- 中央: Google Maps表示
- 右サイドバー: 営業先リスト・検索・統計

### モバイル版（768px以下）
- 画面下部の3つのボタンで画面を切り替え
  - 🧠 インサイト: 営業情報分析
  - 🗺️ マップ: 地図画面
  - 📋 営業先: 営業先リスト
- 各画面が全画面表示に切り替わる

## 使い方

1. MapApp.htmlをブラウザで開く
2. PCではサイドバーが両側に表示
3. スマホでは画面下部のボタンで切り替え

## 技術仕様

- HTML5 + CSS3 + JavaScript
- Google Maps JavaScript API
- レスポンシブデザイン（メディアクエリ使用）
- 画面幅768px以下で自動的にモバイルUIに切り替え
