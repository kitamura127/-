# 営業リスト管理システム - リファクタリング完了

## 概要
Google Apps Scriptで作成された営業先管理システムをリファクタリングしました。1つの大きなファイル（約1000行）を機能ごとに10個のモジュールに分割し、保守性と可読性を大幅に向上させました。

## リファクタリングの主な改善点

### 1. ファイル構造の整理
元のコード（1ファイル）を以下の10ファイルに分割:

```
├── Config.gs              # 設定定数
├── Utilities.gs           # 共通ヘルパー関数
├── AddressService.gs      # 住所・座標取得サービス
├── TeikokyService.gs      # 帝国データバンクPDF検索
├── KentsuService.gs       # 建通新聞メール監視
├── IntelligenceService.gs # 営業インテリジェンス（Gemini AI）
├── CompanyService.gs      # 会社名クリーンアップ
├── MapService.gs          # マップデータ・統計
├── Menu.gs                # メニュー・UI
└── Main.gs                # メイン処理・Webアプリ
```

### 2. 設定の一元管理
- すべての定数を `Config.gs` に集約
- 会社名パターン、API設定、カラム定義などを整理
- マジックナンバーを排除

### 3. コードの重複削減
- 共通処理を `Utilities.gs` に集約
- エラーハンドリングの統一
- UI表示処理の標準化

### 4. 関数の責任分離
- 各サービスは独立した責任を持つ
- 依存関係を明確化
- テストしやすい構造

## 主な機能

### 1. 住所自動取得
会社名を入力すると、Google Maps APIで住所と座標を自動取得

### 2. 帝国データバンクPDF検索
Google Driveから会社名で帝国データバンクのPDFを検索

### 3. 建通新聞メール監視
建通新聞からのメールを監視し、大型案件を自動抽出

### 4. 営業インテリジェンス
Gemini AIで全営業マンの訪問履歴を分析し、ビジネスチャンスを抽出

### 5. マップ表示
Google Mapsで営業先を可視化し、訪問履歴や統計を管理

## 移行方法

### Google Apps Scriptへの展開

1. Google スプレッドシートを開く
2. 「拡張機能」→「Apps Script」を選択
3. 既存の`code.gs`を削除
4. 各`.gs`ファイルを順番に作成してコードをコピー
   - Config.gs
   - Utilities.gs
   - AddressService.gs
   - TeikokyService.gs
   - KentsuService.gs
   - IntelligenceService.gs
   - CompanyService.gs
   - MapService.gs
   - Menu.gs
   - Main.gs
5. 保存して実行

### 注意事項
- Google Apps Scriptではすべてのファイルがグローバルスコープで実行されます
- ファイルの読み込み順序は自動的に処理されます
- `MapApp.html`ファイルが別途必要です（元のコードから引き継ぎ）
