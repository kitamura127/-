# 営業先マップアプリケーション

Google Mapsを使用した営業先管理アプリケーションです。

## プロジェクト構造

```
/
├── index.html          # メインHTMLファイル
├── css/
│   └── styles.css      # スタイルシート
└── js/
    ├── config.js       # アプリケーション設定
    ├── utils.js        # ユーティリティ関数
    ├── mapManager.js   # マップ管理
    ├── sidebarManager.js  # サイドバー管理
    ├── dataManager.js  # データ管理
    └── app.js          # メインアプリケーション
```

## リファクタリング内容

### 1. ファイル分割
- 元の単一HTMLファイル（1000行以上）を構造化された複数ファイルに分割
- HTML、CSS、JavaScriptを完全に分離

### 2. モジュール化
JavaScriptを以下のモジュールに分割:

#### config.js
- アプリケーション設定と定数
- マップスタイル
- APIキー
- しきい値などの設定値

#### utils.js
- 汎用ユーティリティ関数
- HTML エスケープ
- 日付フォーマット
- マーカーアイコン生成
- クリップボード操作

#### mapManager.js
- Google Maps の初期化と管理
- マーカーの表示・管理
- 情報ウィンドウの表示
- 現在地追跡機能

#### sidebarManager.js
- 左右サイドバーの管理
- タブ切り替え
- インサイト表示
- 新着案件表示
- 統計情報表示

#### dataManager.js
- データの読み込みと管理
- Google Apps Script との通信
- フィルタリング機能
- 営業マン切り替え

#### app.js
- メインアプリケーションクラス
- 各モジュールの統合
- グローバル関数の定義
- 自動更新の設定

### 3. クラスベース設計
- 各モジュールをクラスとして実装
- 単一責任の原則に従った設計
- メソッドの明確な役割分担

### 4. 保守性の向上
- コードコメントの追加
- 一貫した命名規則
- 重複コードの削減
- エラーハンドリングの改善

## 機能

### マップ機能
- Google Maps による営業先の可視化
- カスタムマーカー（形状・色による区分表示）
- 現在地追跡
- ルート検索

### サイドバー機能
- 左サイドバー：インサイトと新着案件
- 右サイドバー：営業先リスト
- 検索・フィルタリング
- 訪問履歴管理

### データ管理
- Google Spreadsheet との連携
- 訪問記録の追加
- 月次統計の表示
- 複数営業マンのデータ切り替え

### インテリジェンス機能
- 営業インサイトの自動分析
- 新着案件の検出
- 訪問状況の可視化

## 使用方法

1. Google Apps Script 環境で使用する場合：
   - すべてのファイルを Google Apps Script プロジェクトに追加
   - index.html をメインHTMLとして設定

2. ローカル環境で開発する場合：
   - index.html をブラウザで開く
   - Google Apps Script 機能は動作しません（モックデータでテスト可能）

## ブラウザ対応

- Chrome (推奨)
- Firefox
- Safari
- Edge

## 依存関係

- Google Maps JavaScript API
- Google Apps Script (オプション)

## 設定

js/config.js で以下を設定できます：
- Google Maps API キー
- デフォルトのマップ中心位置
- 訪問状況のしきい値
- 自動更新間隔
- マップスタイル

## ライセンス

このプロジェクトは営業支援ツールとして開発されています。
