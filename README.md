# 営業先管理システム - リファクタリング版

Google Apps Scriptで動作する営業先管理システムです。スプレッドシートとGoogle Maps APIを連携し、営業活動を効率化します。

## リファクタリングの概要

元の単一ファイル（約1500行）を、保守性と可読性を向上させるため、機能ごとに8つのモジュールに分割しました。

### 改善点

1. **モジュール分割**: 機能ごとにファイルを分離し、責務を明確化
2. **コードの重複削減**: 共通処理を関数化して再利用性を向上
3. **定数の整理**: マジックナンバーや文字列を設定ファイルに集約
4. **エラーハンドリングの改善**: エラーメッセージの整形と統一
5. **JSDocコメント追加**: 各関数の役割とパラメータを明記
6. **命名の改善**: より分かりやすい関数名・変数名に統一

## ファイル構成

```
src/
├── Config.gs                  # 設定定数
├── Utils.gs                   # 共通ユーティリティ関数
├── Main.gs                    # メインエントリーポイント
├── SheetService.gs            # シート操作サービス
├── GeocodingService.gs        # ジオコーディングサービス
├── IntelligenceService.gs    # 営業インテリジェンスサービス
├── KentsuEmailService.gs     # 建通新聞メール監視サービス
└── UIHandlers.gs              # UIハンドラー
```

### 各ファイルの役割

#### Config.gs
- アプリケーション全体で使用する設定値を管理
- シート名、カラムインデックス、API設定
- 建通新聞、営業インテリジェンスの設定
- 会社名クリーンアップ用キーワード

#### Utils.gs
- 共通のユーティリティ関数
- セル操作（取得/更新）
- 文字列処理（正規化、クリーンアップ）
- JSON安全パース
- トリガー管理

#### Main.gs
- Webアプリのエントリーポイント（`doGet`）
- フォーム送信トリガー（`onFormSubmit`）
- セル編集トリガー（`onEditInstallable`）

#### SheetService.gs
- スプレッドシートのデータ取得・更新
- 行データの補完（住所、座標、Webサイト）
- 会社名のクリーンアップ
- 訪問履歴の管理
- 月次統計の集計

#### GeocodingService.gs
- Google Maps APIを使用した住所・座標変換
- 住所のジオコーディング
- 英語住所の日本語変換
- 座標から住所の逆引き

#### IntelligenceService.gs
- Gemini APIを使用した営業データ分析
- 全営業マンのデータ収集
- AIによるビジネスチャンスの抽出
- インサイトの保存・取得

#### KentsuEmailService.gs
- Gmailから建通新聞のメールを監視
- メール本文から案件情報を抽出
- 案件の一時保存と登録

#### UIHandlers.gs
- ユーザーインターフェース関連の処理
- メニュー構築
- ダイアログ表示
- トリガーの設定・削除

## 主な機能

### 1. 住所・座標の自動取得
- 会社名を入力すると、Google Maps APIで住所と座標を自動取得
- 英語住所を日本語に変換
- 会社名から不要な情報（地名、業種名）を自動削除

### 2. 営業先マップ表示
- Google Mapsで営業先を可視化
- 訪問履歴の記録と表示
- 区分（戦略予材、現場など）による色分け

### 3. 営業インテリジェンス
- Gemini AIで営業データを分析
- 繁忙情報、新規物件情報などのビジネスチャンスを抽出
- 複数営業マンのデータを横断分析

### 4. 建通新聞メール監視
- Gmailから建通新聞のメールを自動監視
- 大規模案件（5000万円以上）を自動抽出
- マップ上で新着案件を確認可能

### 5. 月次統計
- 戦略予材の訪問実績を集計
- 目標達成状況の可視化

## セットアップ

### 1. Google Apps Scriptプロジェクトの作成

1. Google Sheetsを開く
2. 「拡張機能」→「Apps Script」を選択
3. 各`.gs`ファイルの内容をコピー＆ペースト

### 2. API設定

#### Google Maps API
1. [Google Cloud Console](https://console.cloud.google.com/)でプロジェクトを作成
2. Maps JavaScript API と Geocoding API を有効化
3. APIキーを取得
4. `Config.gs`の`GOOGLE_MAPS_API_KEY`に設定

#### Gemini API（オプション）
1. [Google AI Studio](https://makersuite.google.com/app/apikey)でAPIキーを取得
2. スプレッドシートのメニュー「営業リスト」→「営業インテリジェンス」→「API設定」

### 3. トリガーの設定

#### 住所自動取得
- メニュー「営業リスト」→「住所自動取得を有効化」

#### 営業インテリジェンス（12時間ごとの自動分析）
- メニュー「営業リスト」→「営業インテリジェンス」→「自動分析開始」

#### 建通新聞メール監視
- メニュー「営業リスト」→「建通新聞」→「監視開始」

## 使い方

### 基本操作

1. **会社名を入力**: B列に会社名を入力すると、自動で住所と座標を取得
2. **マップで確認**: メニュー「📍 マップで確認」でマップを表示
3. **訪問記録**: マップ上のマーカーをクリックして訪問履歴を追加

### バッチ処理

- **選択範囲を補完**: 選択した範囲の行を一括処理
- **全行を補完**: シート全体を一括処理
- **住所を日本語化**: 英語住所を日本語に一括変換

## トラブルシューティング

### 住所が取得できない
- APIキーが正しく設定されているか確認
- Google Maps APIが有効になっているか確認
- API使用量の上限に達していないか確認

### トリガーが動作しない
- トリガーが正しく設定されているか確認（「拡張機能」→「Apps Script」→「トリガー」）
- スクリプトの承認が必要な場合があります

### Gemini API エラー
- APIキーが正しく設定されているか確認
- Gemini APIが利用可能な地域か確認
- API使用量の上限に達していないか確認
