# 営業先マップ - モバイル対応版

## 変更点

### ✨ モバイルフレンドリーなUI

このバージョンでは、スマートフォンでも快適に操作できるように以下の改善を加えました：

#### 📱 レスポンシブデザイン
- **画面幅768px以下（スマートフォン）**：サイドバーが全画面表示に変更
- **画面幅769px〜1024px（タブレット）**：サイドバーの幅を最適化
- **画面幅360px以下（小型スマホ）**：フォントサイズをさらに調整

#### 👆 タッチ操作の最適化
- すべてのボタンの最小サイズを**44px**に拡大（Appleのガイドラインに準拠）
- タップ領域を十分に確保
- タップハイライトを無効化してネイティブアプリのような体験を実現

#### 🎨 モバイルUIの改善
- **サイドバー**：PC版では左右に配置、モバイル版では全画面オーバーレイ
- **トグルボタン**：モバイルでは画面端の円形ボタンに変更
- **フォントサイズ**：モバイルで14px〜15pxに拡大（PC版は12px〜13px）
- **パディング**：すべての要素で余白を拡大し、タップしやすく

#### 📐 レイアウト調整
- **スプレッドシート表示**：モバイルでは画面の50%を使用（PC版は可変）
- **コントロール**：モバイルでは縦並びに配置し、各ボタンを全幅に
- **情報ウィンドウ**：モバイルでは画面幅の90%まで拡大

## 使用方法

### Google Apps Scriptへのデプロイ

1. Google Apps Scriptエディタで新しいHTMLファイルを作成
2. ファイル名を`MapApp`に設定
3. `MapApp.html`の内容を全てコピー＆ペースト
4. `Code.gs`に既存のバックエンドコードをコピー
5. デプロイして完了！

### モバイルでの操作方法

- **📍 左上の丸ボタン**：営業インテリジェンス（インサイト・新着案件）の表示/非表示
- **📍 右上の丸ボタン**：営業先リスト（サイドバー）の表示/非表示
- **🎯 全体表示ボタン**：すべてのマーカーが見えるように地図をズーム
- **📍 現在地ボタン**：現在地を追跡してマップに表示
- **▲ 下部のボタン**：スプレッドシートの表示/非表示
