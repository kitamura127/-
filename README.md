# 建設作業員派遣 営業支援アプリ

Google Apps Scriptベースの営業支援アプリケーションです。営業先の管理、訪問履歴の記録、そしてAIによる訴求内容の自動提案機能を提供します。

## 主な機能

### 1. 営業先マップ表示
- Google Mapsで営業先を可視化
- 区分（タネ未満、戦略予材、現場、その他）ごとに異なるマーカー形状で表示
- 訪問履歴に基づいた色分け（最近訪問、要注意、要訪問）

### 2. 訪問履歴管理
- 訪問日とメモを記録
- 訪問頻度を自動集計
- 今月の訪問目標達成率を表示

### 3. **🆕 AI訴求提案機能**
お客様のお困りごとを入力すると、当社の15の強みに基づいて、AIが最適な訴求内容を自動生成します。

#### 当社の強み
1. **価格（Cost）** - 1人当たり22,000円前後、固定費削減
2. **アフターフォロー（Follow）** - 災害・クレーム対応が優秀
3. **安全（Safety）** - 充実した安全教育
4. **教育（Training）** - 未経験者への教育実施
5. **安定基盤（Base）** - 年商100億、全国シェアNo1
6. **将来性（Potential）** - 毎年100名規模で増員
7. **若年齢（Young）** - 平均年齢40代後半
8. **装備（Equipment）** - 作業道具を持参
9. **動員力（Capacity）** - 総員1500名の供給力
10. **法令遵守（Compliance）** - 社保加入率98%、CCUS80%
11. **適材配置（Matching）** - 資格保有者・経験者の配置
12. **書類対応（Document）** - 各種安全書類に対応
13. **職長制度（Leader）** - 職長資格保有者700名
14. **実績（Record）** - ゼネコン現場の実績多数
15. **担当営業（Sales）** - 優秀な営業スタッフ

#### 使い方
1. マップ上の営業先マーカーをクリック
2. 情報ウィンドウの「AI訴求提案」セクションにお困りごとを入力
   - 例：「社会保険の揃った作業員が不足している」
   - 例：「そもそも人手が足りない」
3. 「提案を生成」ボタンをクリック
4. AIが3つの最適な強みを選んで訴求内容を提案
5. 「この提案をメモに追加」で提案内容をスプレッドシートに保存

#### 提案例
**お困りごと:** 「社会保険の揃った作業員が不足している」

**AI提案:**
- **法令遵守（Compliance）** - 社会保険加入率98%、CCUS加入率80%で、コンプライアンスリスクを回避できます。
- **動員力（Capacity）** - 総員1500名の供給力で、必要な作業員を迅速に手配可能です。
- **安定基盤（Base）** - 年商100億、全国シェアNo1の安定した経営基盤で、長期的に安心して取引できます。

### 4. 営業インテリジェンス
- 全営業マンの訪問履歴を分析
- ビジネスチャンス（繁忙情報、新規物件等）を自動抽出
- 12時間ごとに自動分析

### 5. 建通新聞連携
- 建通新聞のメールから案件情報を自動抽出
- 5000万円以上の案件を自動登録

## セットアップ

### 1. Google Apps Scriptにコードを配置
1. Google スプレッドシートを開く
2. 「拡張機能」→「Apps Script」を選択
3. `Code.gs` の内容をコピー&ペースト
4. 「ファイル」→「HTML ファイル」を選択し、`MapApp`という名前で作成
5. `MapApp.html` の内容をコピー&ペースト

### 2. Gemini API キーの設定
1. [Google AI Studio](https://makersuite.google.com/app/apikey) でAPIキーを取得
2. スプレッドシートで「営業リスト」→「営業インテリジェンス」→「API設定」を選択
3. APIキーを入力

### 3. トリガーの設定
1. 「営業リスト」→「住所自動取得を有効化」を実行
2. 「営業リスト」→「営業インテリジェンス」→「自動分析開始」を実行（オプション）
3. 「営業リスト」→「建通新聞」→「監視開始」を実行（オプション）

## 必要な権限

- Gemini API
- Gmail API（建通新聞連携を使用する場合）
